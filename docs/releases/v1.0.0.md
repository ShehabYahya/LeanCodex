# v1.0.0 — Durable, resumable DSH session access

LeanCodex, published at the time as **DSH CLI Session**, v1 is the first publication-ready release of the Codex plugin + MCP bridge for an already-running DeepSeek Harness session.

Instead of repeatedly scraping a large agent transcript, the host gets a compact stateful contract:

**send once → keep the assignment handle → wait from a cursor → receive finalized output → resume safely.**

## Highlights

- **Native request correlation** — output is tied to DSH's request identity, not prompt-prefix matching.
- **Output-only incremental feed** — finalized outward messages and compact lifecycle state without private reasoning or raw tool traces.
- **Signed resumable cursors** — stable replay and lossless continuation for long messages.
- **Retry-safe admission** — ambiguous send outcomes preserve the same logical assignment/request identity.
- **Connection-safe watching** — observer timeouts do not become fake task failures.
- **Bounded evidence** — selectively read assignment-owned output and published artifacts.
- **Model-neutral interface** — the plugin documents tool semantics without prescribing how the host model should prompt or orchestrate.
- **Local security boundary** — loopback-only DSH transport, local credential handling, redaction, and artifact validation.

## Installation

Add the repository as a Codex plugin marketplace:

```bash
codex plugin marketplace add ShehabYahya/LeanCodex
```

Restart ChatGPT Desktop, open the plugin directory, select the marketplace, and install **LeanCodex**.

## Verification

The v1 release is covered by deterministic regression tests plus a real MCP stdio contract test. CI verifies request correlation, replay, chunking, retry/timeout state separation, reasoning/tool filtering, evidence ownership, artifact protections, credential redaction, store retention, typed MCP schemas, and the absence of model-specific behavior instructions.

## Known limitations

- The verified delivery baseline is bounded wait-based MCP tool results; unsolicited model wakeup/push is not claimed.
- Runtime compatibility depends on the locally installed DeepSeek Harness version.
- No paid live model/provider smoke test is required by CI.
